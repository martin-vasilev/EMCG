Software

Open tools for eye-movement research

Reusable software is part of our commitment to transparent and reproducible research.

eyemovements

An R package for processing and analysing eye-movement data, including fixation detection and common preprocessing utilities.

EMreading

An R package for automatic preprocessing of EyeLink eye-movement data collected during reading.

View on GitHub →

Eyelink screen recorder

A Python script for recording Eyelink data in the background while using other applications (e.g., a browser).

View on GitHub →

Collection of novel sounds

A collection of 148 novel environmental sounds for use in auditory distraction experiments. All public domain and saved in 150, 200, and 250 ms durations.
