# Eye-Movement Control Group website

Static lab website based on the visual language and section structure of the YMatter Lab Hugo Academic Lab Template.

## Preview locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
Upload the contents to a GitHub repository and enable Pages from the main branch/root folder.

## Main files
- `index.html` — homepage
- `research.html` — research themes
- `people.html` — group members
- `publications.html` — publications
- `software.html` — open-source software
- `contact.html` — contact page
- `assets/css/style.css` — original template CSS
- `assets/css/custom.css` — lab-specific additions
